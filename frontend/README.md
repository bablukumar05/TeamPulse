# TeamPulse —

Enterprise Team & Employee Management Platform Frontend built with React, Vite, Tailwind CSS, Recharts, and Socket.IO.

## 🚀 Features
- **Admin Dashboard**: Analytics, employee management, workload distribution, and leave approvals.
- **Employee Portal**: Task tracking, timelogs, sprint progress, and personal document vault.
- **Real-time Team Chat**: Instant messaging powered by Socket.IO.
- **Performance Optimized**: Code-splitting, React.lazy, and instant hydration.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS
- **Icons & UI**: Lucide React, React Icons, Canvas Confetti
- **Charts**: Recharts
- **State & Routing**: React Context API

## ⚡ Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Configuration**:
   Create a `.env` file in the root directory:
   ```env
   VITE_API_URL=http://localhost:5000
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```
